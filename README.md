# CYBERPIX
Top-down 2D cyberpunk action RPG. Open `cyberpix.html` in any modern browser (single file, no install).

## Controls
WASD move - Mouse aim/fire - Shift dash - E interact (hold on terminals) - R reload - 1-4 / wheel / C weapon wheel
G grenade - H MaxDoc - Q quickhack target - X cycle hack - V or RMB melee - Tab hub - Esc pause (all rebindable)

## Missions
Main: Back on the Street > Down the Rust Line > Dead Drop > Arclight Job > Chrome Brute (boss, elevator = ending)
Side: Static in the Wires, Gang Cleanup, Lost Cargo, Bounty: Rust Rat Captain

## Files
cyberpix.html (game) | index.html + assets.js data.js game.js ui.js (source) | build.py (inline into one file) |
export_assets.js (regenerates assets/) | assets/ (PNG sheets, atlas JSON, 239 sprites) | assets.html (browse)
