# CYBERPIX
Top-down 2D cyberpunk action RPG.

**Play now: https://qusai64574-gif.github.io/cyberpix/**

Runs in any modern browser — phone, tablet, controller or PC. No install.

## Controls
Keyboard/mouse: WASD move - Mouse aim/fire - Shift dash - E interact (hold on terminals) - R reload - 1-4 / wheel / C weapon wheel
G grenade - H MaxDoc - Q quickhack target - X cycle hack - V or RMB melee - Tab hub - Esc pause (all rebindable)

Touch: left thumb = floating movement stick, right thumb = aim and fire, on-screen buttons for fire, melee, reload, dash, hack, MaxDoc, interact, hub and pause.

Controller: left stick move - right stick aim - RT fire - A interact - B melee - X grenade - Y reload - LB/RB switch weapon - LT dash - Start pause.

The game enters fullscreen on your first tap or click, and switches control scheme automatically to whatever you are using.

## Missions
Main: Back on the Street > Down the Rust Line > Dead Drop > Arclight Job > Chrome Brute (boss, elevator = ending)
Side: Static in the Wires, Gang Cleanup, Lost Cargo, Bounty: Rust Rat Captain
